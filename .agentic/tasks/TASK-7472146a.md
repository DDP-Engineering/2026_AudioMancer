## Design

Components touched: Character Voices page (`character_voices_page.py`), its
state service (`character_voices_state_service.py`), and the shared
localization tables (`ui_state_service.py`). The controller is untouched.

Interface change (REQ-NFR-9792c51a): `set_character_voices_state` loses four
of its nineteen keyword parameters - `original_language`,
`translated_language`, `assignment_mode_label`, and `language_entries`. It is
called in exactly one place, `MainWindow._refresh_character_voices_page_state`,
by dictionary splat of `build_character_voices_state(...)`, so the payload and
the signature must lose the same four keys in the same change or the splat
raises. `selected_voice_language` stays: `current_voice_language()` feeds
`current_editor_payload()`, sample generation, and preview-text resolution.

Data (REQ-NFR-9792c51a): `_voice_language_state` stops returning the original
and translated language labels and narrows to a three-tuple. Its
translation-document read stays, because that block also decides
`translation_ready`, which the page notes still use. `language_entries` keeps
its life *inside* the service - it is what validates the saved voice language
against the selectable codes - and only leaves the payload.
`_assignment_mode_label` likewise stays, because the operator notes still
format it into a sentence; only the payload key goes.

UI (REQ-UX-7a0a2d7a): the four `QGroupBox` widgets, their value labels, the
`indicator_row` layout, the `_set_language_labels` and
`_set_voice_language_label` helpers, the `_language_indicator_title` helper,
and their four `apply_language` lines all go. `header_layout` then wraps only
`title_row`, so it collapses into the title row directly. The four orphaned
`character_voices.original_language`, `.translated_language`,
`.assignment_mode`, and `.voice_language` keys leave both the English and the
Romanian table.

Scope correction (REQ-FUNC-3091aae8): that legacy requirement bundles four
behaviors in one sentence, one of them "render language and sizing
indicators". Only the language half is being removed, so the requirement is
narrowed and loses one linked test rather than being retired whole.

Rejected alternative: hiding the boxes with `setVisible(False)` and leaving
the payload intact. It is a smaller diff and reversible, but it leaves the
state service resolving a translated-language code out of the translation
document on every refresh for a widget nobody can see, and leaves the next
reader unable to tell dead plumbing from live. The operator asked for the
indicators removed, not hidden.

Test seams: REQ-UX-7a0a2d7a attaches at `tests/test_character_voices_page.py`,
asserting a constructed page has no attribute for any of the four boxes or
their labels. REQ-NFR-9792c51a attaches at
`tests/test_character_voices_state_service.py`, asserting the four keys are
absent and `selected_voice_language` present in the inactive, empty-project,
and manifest-error payloads. The existing
`test_character_voices_page_header_indicators_render_languages_and_assignment_mode`
is deleted, and every `set_character_voices_state(...)` call across the page,
controller, localization, main-window, and contract suites drops the four
arguments.

Files: the three source files above, plus
`tests/test_character_voices_page.py`,
`tests/test_character_voices_state_service.py`,
`tests/test_character_voices_ui_controller.py`,
`tests/test_ui_localization_coverage.py`, `tests/test_main_window_project_flow.py`,
and `tests/test_ui_page_contract.py` as the call sites require.
