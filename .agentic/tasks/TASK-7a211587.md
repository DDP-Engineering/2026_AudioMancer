## Design

- Components: the Audio Blocks service owns artifact/regeneration truth, the state service projects eligible actions, the page consumes row eligibility, the controller owns selected pause timing, and Audio Assembly remains an unchanged consumer.
- Interface: keep every public signature and persisted field unchanged while deriving truthful `audio_relative_path`, `audio_can_play`, `can_play`, and `can_regenerate_selected` values (REQ-FUNC-ee6222b7, REQ-UX-1d1e98a7).
- Service decision: centralize real-WAV ownership around generated, non-metadata-only rows plus current artifact validation; reload Scene Ambience as metadata-only only when no valid generated WAV exists (REQ-FUNC-ee6222b7).
- Regeneration decision: use one eligibility predicate in the direct service guard and state projection, with Scene Ambience explicitly eligible and pause/indication metadata rows ineligible (REQ-FUNC-94720d7e, REQ-UX-1d1e98a7).
- Playback decision: reuse the existing pause classifier/duration and `QTimer.singleShot` model for selected playback, guarded by playback mode so stop makes a pending completion harmless (REQ-UX-cc9b04c0).
- Data: do not add persisted keys or schema migrations; derived compatibility is repaired at load/state time and compact storage remains unchanged (REQ-FUNC-ee6222b7, REQ-FUNC-94720d7e).
- Rejected alternative: another content-kind denylist only in path derivation would leave playability, regeneration, and real Scene Ambience reload semantics able to drift again.
- Test seams: service load/assembly projection for REQ-FUNC-ee6222b7; direct regeneration with runtime spies for REQ-FUNC-94720d7e; state/page action matrices for REQ-UX-1d1e98a7; controller timer, stop, completion, and warning spies for REQ-UX-cc9b04c0.
- Expected source files: `audio_blocks_service.py`, `audio_blocks_state_service.py`, `audio_blocks_ui_controller.py`, and `audio_blocks_page.py`; expected regressions are in their four focused test modules plus `test_audio_assembly_service.py` only if needed for the consumer projection.
