## Design

- Components: persistence, Character Voices, Narrator Voice, TTS Audio Blocks, Audio Assembly, and Project Lifecycle are touched under REQ-REL-ee8f9ed0 and REQ-FUNC-4cc6cf8c.
- Interface: add public `persistence_service.write_bytes_atomic(target_path, payload)` beside `write_text_atomic`, and import that exact function into each complete-WAV byte owner under REQ-REL-ee8f9ed0.
- Storage: retain same-directory `.<target>.*.tmp`, fsync, atomic replacement, best-effort owned-temp cleanup, original `OSError` propagation, metadata order, cancellation points, and downstream WAV validation under REQ-REL-ee8f9ed0.
- Storage: keep Audio Assembly streamed `.tmp` composition and mix publication unchanged because those temps are transaction outputs built incrementally rather than complete in-memory byte payloads under REQ-REL-ee8f9ed0.
- Interface: keep `default_audio_assembly_settings` and `normalize_audio_assembly_settings` public and domain-owned, while project workspace uses local imports at its three manifest call sites to avoid the existing reverse dependency under REQ-FUNC-4cc6cf8c.
- Rejected alternative: a module-level workspace import of Audio Assembly would create a partially initialized cycle because Audio Assembly already imports workspace, while preserving delegating duplicate wrappers would retain unnecessary names under REQ-FUNC-4cc6cf8c.
- Test seams: persistence failure injection plus service-level monkeypatches cover byte routing, and manifest call interception, boundary comparison, save/load, and fresh-process import orders cover settings normalization.
- Expected code/test files: the six named services plus `test_persistence_service.py`, Character Voices, Narrator, Audio Blocks, Audio Assembly, and project-workspace service tests; AEGIS requirements, journal, knowledge, and `CHANGELOG.md` complete delivery.
