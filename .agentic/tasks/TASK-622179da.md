## Design

**Approach**
- Move per-chunk prompt setup, provider calls, segment normalization and optional ambience into speech_blocks_generation_service. Batch and Split Chunk use the same preparation and generator.
- Keep source resolution, project document, checkpoints, operator edits and workflow orchestration in speech_blocks_service.
- REQ-FUNC-6f65b68e: checkpoint absolute character offsets into the exact source chunk and keep the chunk active through optional ambience. Resume plans only the remainder. Operator edits and a selected re-split of a different chunk keep the active cursor and batch instructions.
- REQ-REL-a54e058d and REQ-FUNC-42f8c617: a speech refusal skips the chunk. The provider preserves ValueError compatibility with a distinct refusal subtype. An ambience refusal keeps the speech and adds an editable review warning. Cancellation remains distinct.

**Interfaces and data**
- Store next_source_offset with the active chunk ID and matching source fingerprint. The offset counts characters in the request slices, independently of the model output and operator edits.
- Existing checkpoints without an offset may regenerate only the unfinished chunk. Preserve completed chunks, their approval state, and the original instructions even if an older approval set the document to a reviewed status.
- REQ-FUNC-b01347e6 and REQ-FUNC-539625c4: normalize AI narration to the narrator and split the unwrapped spoken dialogue while retaining exact source slices.
- REQ-UX-9e2c737d: share the AI profile predicate between generation, page state and controller. Keep resume reachable when the active chunk already has visible rows.

**Files and test seams**
- Run existing Speech Blocks service, normalization, single-document and focused UI regressions. Vary the actual request segmentation budget and inject provider refusal/cancellation.
- Update bilingual help and Unreleased changelog.

**Risks and open decisions**
- Partial chunks are published during the run. Reserve the spoken IDs before allocating ambience IDs. Checkpoint deterministic speech before optional ambience and finalize running end-of-source checkpoints without reprocessing.
- Provider tests use simulated responses.

**Requirement map**
- REQ-FUNC-6f65b68e: offset and source coverage regression.
- REQ-REL-a54e058d and REQ-FUNC-42f8c617: distinguish the two provider failures.
- REQ-FUNC-b01347e6 and REQ-FUNC-539625c4: generated block normalization regressions.
- REQ-UX-9e2c737d: page and controller profile checks.
