- Interface: `analyze_book(...)` consumes completed canonical chunks plus normalized profile/target language/cancellation/progress callbacks; state projection exposes report freshness, resumability, controls, and standard operation status without adding a canonical workflow stage (`REQ-FUNC-e73cba08`, `REQ-UX-7a9404e3`, `REQ-FUNC-4fad33e4`).

- Reset/invalidation: Book Analysis owns only its document, logs, and compact supporting-operation summary; chunk mutation marks prior results stale/non-resumable but never cascades into canonical downstream artifacts (`REQ-DATA-8e648624`, `REQ-FUNC-4fad33e4`).
