## Design

- Components: `MainWindow` captures the page-owned live AI profile before rebuilding selector entries (REQ-UX-850b356e).
- Components: the existing narrator profile-state builder remains the sole enabled/default/first resolver (REQ-UX-f6f92026, REQ-UX-cbed137b).
- Components: the narrator definition service remains the sole strict-document language migration writer (REQ-FUNC-4f57d7ae, REQ-FUNC-0fff5848, REQ-FUNC-206af389).
- Interface: pass `NaratorVoicePage.current_ai_profile_id()` through the existing optional `selected_profile_id` parameter; no signal or persisted format changes (REQ-UX-f6f92026, REQ-UX-850b356e, REQ-UX-cbed137b).
- Data: compare stored preview text exactly with the canonical default resolved from each profile's prior language before choosing whether to localize it (REQ-FUNC-4f57d7ae, REQ-FUNC-0fff5848).
- Data: compare the migrated profile list with the validated stored list and call the existing strict atomic writer only when they differ (REQ-FUNC-206af389).
- Sample contract: retain each profile's sample mapping byte-for-byte within the validated document structure during profile-language migration (REQ-FUNC-4f57d7ae).
- Rejected alternative: persisting the session-local AI profile identifier was rejected because the page already owns the live choice and duplicate durable state is unnecessary (REQ-UX-850b356e).
- Rejected alternative: moving language migration into every language-change controller was rejected because the state service already owns effective-language resolution and conditional persistence is the smallest complete fix (REQ-FUNC-206af389).
- Test seams: state-service tests cover initial and fallback resolution; main-window and controller tests cover direct and narrator-list refresh preservation (REQ-UX-f6f92026, REQ-UX-850b356e, REQ-UX-cbed137b).
- Test seams: narrator-service tests cover authored, AI, canonical, mixed, unchanged, sample, and strict-contract cases; a state-service writer spy covers repeated refresh (REQ-FUNC-4f57d7ae, REQ-FUNC-0fff5848, REQ-FUNC-206af389).
- Expected source changes are `main_window.py` and `narrator_definition_service.py`; focused tests, requirements, journal, Voice Profiles knowledge, both user guides, and Unreleased changelog complete delivery preparation.
