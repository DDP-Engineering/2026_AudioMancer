## Design

**Approach**
- Read Assembly report once per request. Use generated records with safe local WAV paths for lightweight Home readiness, then verify complete PCM frames in the worker.
- Build the ZIP manifest from the validated member inventory. Disclose incomplete reports or omitted files with the actual count.
- Isolate exceptions per export row. Home dispatches only the requested export and reports partial success from the worker result.
- Move text projection to its own service and keep routing in Project Export.
- Reuse atomic text persistence, add a common ZIP writer for stage exports and snapshots, and reuse the operation runner.

**Interfaces and data**
- Home readiness gains partial and invalid-artifact statuses. Worker returns a publication path and partial count.
- ZIP writer accepts ordered source/text entries, progress and cancellation, creates an owned sibling temporary file and replaces on success.
- Retain text and archive service entry points and file layouts. Validate external destinations before writing. Skip escaped sources and linked snapshot directories.

**Files and test seams**
- project_export_service and project_export_text_service for artifact selection, text projections and Assembly manifests.
- archive_writer and project_snapshot_service for ZIP writes and cancellation.
- operation_runtime_service for destination containment and character_voices_service for strict export-only plan reads.
- home_ui_controller, home_page and ui_state_service for background dispatch and EN/RO labels. Focused export, Home, and snapshot tests plus both guides and changelog.

**Risks and open decisions**
- Cancel between ZIP members. The UI serializes background operations. Snapshot is a filesystem projection.
- Default planned count to report records when old report fields are absent. Missing or corrupt WAVs never count as exported.

**Requirement map**
- REQ-FUNC-377deb62, REQ-FUNC-c0245dda, REQ-REL-52502997: generated PCM validation, actual inventory, empty archive refusal.
- REQ-UX-dda2d417, REQ-REL-8015aa42, REQ-UX-49f4cab2: Home partial result, readiness isolation, background dispatch.
- REQ-REL-80edd255, REQ-REL-45187235, REQ-FUNC-efcaeeed: cancellation-safe ZIP and atomic text publication.
- REQ-FUNC-2aa2abfc: move the AI settings projection with its existing test.
- REQ-SEC-db448904, REQ-SEC-cdbd652c, REQ-REL-3b9c207e: safe primary and auxiliary sources, outside replacement directory and resolved destination, and original failure preservation.
